# v5.12.0: Tagging Fixes & Card Detail Search

**Released**: 2026-09-02

## Highlights

A tagging-focused release: new generic `Token Multiplier`/`Token Modifier: Additive`/`Counter Multiplier`/`Kindred Support` tags help more cards surface for the right Deck Builder themes, Changeling cards now count toward Kindred themes during creature addition, several dead/broken regex patterns were found and fixed (including `Midrange`, `Removal`, `Lifedrain`, and phasing scope detection), and Deck Builder protection picks got smarter about Equipment/Aura counts and dual-scope cards. Also: card detail pages now have their own search bar with the same tag/theme autocomplete as the Card Browser, and several pieces of Deck Builder wizard dead code were removed.

## Added

- Tagging: cards that generically double token counts (Doubling Season, Anointed Procession) now show up for any "[X] Tokens" theme in the Deck Builder, even if they weren't tagged for that specific token type.
- Tagging: cards that add a bonus token on top of what's created, generically (Academy Manufactor, Chatterfang) now show up for any "[X] Tokens" theme in the Deck Builder too.
- Tagging: cards that generically double counter counts (Gilder Bairn) now show up for any "[X] Counters" theme in the Deck Builder.
- Tagging: cards that let you name a creature type for generic tribal support (Adaptive Automaton, Arcane Adaptation) now show up for any "{X} Kindred" theme in the Deck Builder.

## Changed

- Deck Builder: Protection picks now cap Equipment and Auras at 2-3 total combined, since EDHREC favors Equipment heavily but it usually can't protect a creature the turn it's cast. Other protection spells fill the rest of the target as before.
- Deck Builder: Protection picks now also include cards that protect your board in one mode but can also hit an opponent's in another (e.g. the dual-scope phasing cards below), instead of excluding them entirely.
- Deck Builder: finishing a build now automatically takes you to the finished deck's summary page instead of leaving you on the builder screen.
- Web: card detail pages now have their own search bar with the same tag/theme autocomplete suggestions as the Card Browser and Owned Library, so you can search for another card without going back first.

## Fixed

- Deck Builder: Changeling cards (Morophon the Boundless, Prideful Feastling, etc.), which are every creature type per the game's own rules, now show up in the candidate pool for any Kindred theme (same as generic tribal-support cards like Adaptive Automaton/Roaming Throne already did), instead of only counting toward their literal printed type. This now applies during the actual creature-addition step (not just the end-of-build backfill fallback) and in the manual builder's card browser, so Kindred decks with low inherent cards no longer undercount available creatures or bury Changelings at the bottom of the Creatures list.
- Tagging: fixed several dead/broken regex patterns found in a tagger audit, most notably `Midrange` (missed ~625 cards due to outdated card-text templating) and `Removal` (missed 107 cards due to a reversed-word-order pattern); also cleaned up `Pillowfort`, `Landfall`, and a batch of other harmless dead patterns. A full re-tag was run to apply the fixes.
- Tagging: cards that phase permanents out (Oubliette, Teferi's Protection, The City on the Edge of Forever, etc.) now correctly get scope-aware `Protective Effects`/`Removal`/`Board Wipes` tags; a bug meant phasing scope detection almost never fired before. Also fixed several narrower pattern gaps, removed an incorrect `Phasing` tag from Sphinx of the Second Sun, and corrected Galadriel's Dismissal, Brokers Confluence, March of Swirling Mist, Slip Out the Back, and similar unqualified-target cards to carry `Protective Effects` + `Removal` instead of an incorrect `Board Wipes`/`Removal`-only tag. A full re-tag was run to apply the fixes.
- Deck Builder: Protection picks were missing most cards tagged only with the generic `Protective Effects` tag (Hexproof/Ward/Shroud/Indestructible/Phasing grants), since the pool filter only recognized tags containing the literal word "protection". Fixed to recognize `Protective Effects` directly.
- Deck Builder: the build wizard's "Back" button led to a leftover route from an older step-by-step flow and rendered the builder page nested inside itself instead of navigating anywhere useful. Removed it since "Restart Build"/"New build" already do what it was meant to do.
- Deck Builder: removed the old step1-4 wizard routes/templates and the broken "Edit in Review" link on the build results page, all leftover dead code from before the current modal-based "Build a New Deck" flow.
- Deck Builder: reopening the "Build a New Deck" modal via the "New build" button mid-session (without a full page reload) caused the Ideal Counts sliders to silently stop updating when dragged (e.g. Ideal Max Creatures stuck showing 28). Fixed a script re-run bug so the sliders wire up correctly every time the modal is reopened.
- Tagging: the `Lifedrain` tag was missing a lot of classic drain cards phrased with a literal repeated number (Blood Artist, Zulaport Cutthroat, Cruel Celebrant, Siege Rhino, Retreat to Hagra, and many more: "each opponent loses 1 life and you gain 1 life"), since it only recognized "gain life equal to/that much life" wording. A full re-tag was run to apply the fix (252 cards now tagged `Lifedrain`, up from 45).
