# v5.1.0: Foil Finish, Color Filters, and Card Transform

**Released**: 2026-07-27

## Highlights

This release adds **foil finish** as a first-class choice alongside printing selection: toggle a card between its nonfoil and foil price/finish anywhere its printing can be chosen, see both prices side by side on the card detail page, and enjoy a rainbow shimmer overlay wherever a foil card's image is shown (saved decks, the builder wizard, the owned library, the card browser, and more).

The card browser and owned library also get richer color filtering: clickable color-identity names (e.g. "Bant") alongside the color pips, and an **Inclusive Match** toggle so a search like "WU" can optionally surface Bant, Esper, and Jeskai cards too, not just exact Azorius matches.

Double-faced, split, flip, and meld cards are also better supported on the card detail page, which now has a **Transform** button to flip between a card's front and back artwork, with both faces' full details always shown.

The public REST API also grows a **public/community deck browsing** surface (`GET /api/v1/decks/public` and its detail/export routes) for the upcoming mobile companion app: no authentication required, mirroring the web UI's "Other Users' Decks" and "Community Builds" sections.

## Added

- Foil finish selection (`POST /api/v1/decks/{filename}/foil`, `POST /api/v1/builds/{id}/foil`) mirroring the existing printing-selection endpoints; `GET /api/v1/decks/{filename}` card entries now include `is_foil`, and `POST /api/price/batch` accepts a `foil_map` so batch pricing (including CSV-with-prices downloads and deck analysis totals) prices each card at its own foil finish
- Card detail page's market price panel shows both the nonfoil and foil TCGPlayer prices together (e.g. "TCG $21.19 / ✨ $38.80"), updating live as you change printing or foil; the foil toggle is hidden for printings with no foil version and locked on for foil-only printings
- A static, rainbow foil overlay shows over the card image anywhere a foil card's image is displayed: card detail page, saved deck view, new-deck and partner commander-selection previews, the deck builder's review stage, the owned card library, the card browser grid, and the commander directory
- Card browser and owned library tiles show clickable guild/shard/wedge/nephilim color-identity names alongside the color pips, and a new "Inclusive Match" filter toggle for color searches
- Card detail page's new "Transform" button flips the card image for double-faced/split/flip/meld cards; both faces' type, mana cost, power/toughness, and oracle text are always shown
- `GET /api/v1/decks/public`: browse other users' public decks and shared community builds with no authentication required, mirroring the web UI's "Other Users' Decks" and "Community Builds" sections
- `GET /api/v1/decks/public/{owner_id}/{filename}` and its `/export` variant: view or download (CSV/TXT/JSON) a specific deck from the `/public` listing, also with no authentication required

## Fixed

- The card browser's color filter now matches color identity regardless of the raw data's letter order (some valid filter selections previously silently returned no results)
- `GET /api/printings/{card_name}` now resolves double-faced/split/flip/meld names ("A // B") to their front face before looking up printings, instead of always returning an empty list for those names

## Upgrade notes

1. Rebuild the container: `docker compose up --build --no-deps -d web`.
2. No new required environment variables or migrations.
