# v5.5.0: Manual Deck Builder

**Released**: 2026-08-04

## Highlights

A new "Build Manually" option lets you pick a commander and build the deck yourself: browse the full legal card pool organized into categorized sections (New Cards, On-Brand Cards, Related Synergy, creature/spell/land types, and role-based sections for Ramp/Removal/Card Draw/Board Wipes/Protection), search with the same Scryfall-style query syntax as the public card API, and add/remove cards one at a time while a live role-health bar and bracket-compliance pill row track your progress. The finished deck saves and exports like any other build, or can be reopened later with a new **Edit Deck** button. The same functionality is also available over the public API via `mode: "manual"` build sessions.

## Added

- Manual Deck Builder: a new "Build Manually" option (sidebar, home page, and the New Deck modal) lets you pick a commander and then browse the full legal card pool yourself, filtering/sorting by role and mana value, searching by name, and adding/removing cards one at a time. A live role-health bar tracks Ramp/Removal/Draw/Lands/Threats against target counts, hovering a pool card surfaces a few alternative options in the same role, and the finished deck can be saved (eligible for Suggested Upgrades and Import Analysis, same as any other deck) or exported as CSV/TXT without saving. Toggle with `ENABLE_MANUAL_BUILDER` (default on).
- Manual Deck Builder: the pool respects your bracket's compliance limits (fully banned cards excluded, capped cards badged), with a live pill row tracking Game Changers, Extra Turns, Mass Land Denial, Nonland Tutors, and Two-Card Combos.
- Manual Deck Builder: an **Edit Deck** button on any deck you own reopens it in the Manual Deck Builder with its commander, cards, bracket, and settings pre-loaded; saving overwrites the original deck file in place.
- Manual Deck Builder: the pool is organized into categorized, independently searchable/paginated sections with a pinned table-of-contents and role-health bar, a "Choose Printing"/foil picker, a "Why this card?" hover panel, a "+ Add Land Package" button, and quantity inputs for basic lands/unlimited-copy cards.
- Manual Deck Builder: the search box supports Scryfall-style query syntax (`t:`, `o:`, `c:`, `id:`, `m:`, `mv:`, `pow:`/`tou:`/`loy:`) in addition to plain name search.
- Card tagging: added a new `Graveyard Hate` tag, separate from `Board Wipes`.
- Public API: `POST /api/v1/builds` now accepts `mode: "manual"`, opening a fully interactive build session (pool browsing, add/remove/set-count, land package, search, suggestions, save) matching the Manual Deck Builder's functionality, including a mana overview in responses and a dedicated `GET /{build_id}/manual/deck` endpoint.

## Changed

- All Cards browser and Owned Library: replaced the color/type/rarity dropdowns and CMC/power/toughness range inputs with a single Scryfall-style search box, matching the syntax used in the Manual Deck Builder and public card API.

## Fixed

- Card database: refreshed the underlying card list and recommendation pipeline; fixed stale "New Cards" results and un-set/joke cards, non-tournament-legal cards, and self-referential Art Series/Alchemy names appearing incorrectly in the pool.
- Card tagging: fixed several false-positive `Ward` and `Board Wipes` tags caused by overly broad text matching.

## Upgrade notes

1. Rebuild the container: `docker compose up --build --no-deps -d web`.
2. New environment variable: `ENABLE_MANUAL_BUILDER` (default `1`); set to `0` to hide the feature.
3. No migrations required; existing decks are unaffected and can optionally be reopened via **Edit Deck**.
