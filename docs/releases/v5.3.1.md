# v5.3.1: Ideal-Defaults Endpoint Fix

**Released**: 2026-08-01

## Highlights

The mobile app's ideal-counts screen was showing a redundant "Creatures" slider alongside the new min/max controls introduced in v5.3.0.

## Fixed

- The public API's `GET /api/v1/builds/ideal-defaults` endpoint listed the legacy `creatures` alias alongside `creatures_max`; `creatures` is now dropped from that endpoint's response (still accepted/returned as before on the build create/read endpoints themselves)

## Upgrade notes

1. Rebuild the container: `docker compose up --build --no-deps -d web`.
2. No new required environment variables or migrations.
