# v5.2.0: Smarter Upgrade Suggestions and Theme Catalog Fixes

**Released**: 2026-07-28

## Highlights

This release makes **Suggested Upgrades** recommendations noticeably more on-theme: scoring now prioritizes your deck's primary theme first, secondary theme second, generalized utility roles (Ramp, Removal, Board Wipes, Card Draw, Protection) third, tertiary theme fourth, and other incidental tag overlaps last. Previously, an off-theme tag carried by even a single deck card (e.g. Blink/ETB on one support piece in an otherwise Spellslinger deck) could be weighted the same as the deck's real strategy, surfacing thematically irrelevant recommendations. Swap-candidate reasons also now spell out the actual mana-value comparison and role coverage instead of vague summaries.

The theme catalog gets two fixes: literal backslashes no longer appear in the `+0/+1`, `+1/+0`, and `+2/+2 Counters` theme names/descriptions, and example cards/commanders are now properly auto-populated for every theme (the editorial suggestion step was still scanning removed per-color CSV files instead of the current Parquet card data).

Also fixed: Scryfall's bulk data download (used by initial setup, price refresh, and rulings cache) was silently failing after Scryfall replaced the plain-JSON `download_uri` with gzip-compressed JSONL; the downloader now handles the new format transparently.

## Added

- `GET /api/v1/decks/{filename}/compliance`: bracket compliance report (overall PASS/WARN/FAIL plus per-category breakdown) for a saved deck, read from the `_compliance.json` sidecar written at build time
- `POST /api/v1/decks/{filename}/upgrades/swap`: apply a suggested upgrade swap to a saved deck (remove one card, add another), mirroring the web UI's "Suggested Upgrades" apply-swap action

## Changed

- Upgrade suggestions: swap-candidate reasons now spell out the actual mana-value comparison (e.g. "3 vs 5 CMC") and role coverage instead of vague summaries
- Upgrade suggestions: "General" and "Possible" scoring now prioritizes primary theme, secondary theme, generalized utility roles, tertiary theme, and incidental tag overlaps, in that order

## Fixed

- Theme catalog: fixed literal backslashes in the `+0/+1`, `+1/+0`, and `+2/+2 Counters` theme names/descriptions, and removed stale duplicate entries for two of them
- Scryfall bulk data download now handles the gzip-compressed JSONL format Scryfall switched to, instead of silently failing
- Theme catalog example cards/commanders are now auto-populated correctly, reading from the current Parquet card data pipeline instead of removed per-color CSV files

## Upgrade notes

2. No new required environment variables or migrations.
