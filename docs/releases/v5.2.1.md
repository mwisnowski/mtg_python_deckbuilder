# v5.2.1: Printing-Aware CSV Pricing and Image Cache Fix

**Released**: 2026-07-29

## Highlights

Deck CSV exports now price each card using its selected printing (when one has been chosen), instead of always showing the cheapest known printing's price, matching how pricing already worked elsewhere in the app (budget evaluation, deck analysis, JSON exports). The Total summary row reflects the same fix.

Also fixed: the image cache's lightweight "default" download mode could download more than one image for a card when multiple printings tied for the top score; ties are now broken by most recent release date, matching how the default printing is already resolved elsewhere.

## Fixed

- Deck CSV export's Price (TCGPlayer) column (and its Total summary row) now prices a card's selected printing, falling back to the cheapest-by-name price when the selected printing has no price data
- Image cache default-mode downloads no longer fetch duplicate images per card when multiple printings tie for the top score

## Upgrade notes

1. Rebuild the container: `docker compose up --build --no-deps -d web`.
2. No new required environment variables or migrations.
