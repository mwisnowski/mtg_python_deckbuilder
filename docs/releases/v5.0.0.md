# v5.0.0: Choose Printing & Guided Build API

**Released**: 2026-07-24

## Highlights

This release headlines with **Choose Printing**: pick a specific printing (art/set) for any card from a floating picker on its tile, everywhere card tiles show up (build review, Finished Decks, Card Browser, Owned Library, Card Details). Your choice is remembered across pages, round-trips through permalinks, and prices update to match the printing you picked. It's backed by a new per-printing image cache and per-printing price tracking.

Alongside that, the public REST API grows a **guided (stage-by-stage) build mode** with remove-card/undo and rerun-stage support, a deck analysis endpoint, and multi-faced card details, primarily for the upcoming mobile companion app. Land tagging also gets a round of accuracy fixes (fetch lands, tribal lands, ramp detection).

## Added

- **Choose Printing**: a picker button on card tiles across the web build review, Finished Decks (list and thumbnail views), Card Browser, Owned Library, and Card Details opens a list of that card's known printings (art/set thumbnails); your pick swaps the artwork immediately, is remembered across all pages, and is included in permalinks. On the Owned Library it's a visual preview only and doesn't affect owned-card matching.
- **Per-printing pricing**: prices now reflect the specific printing you've chosen instead of always showing the cheapest known printing.
- **Guided deck building (public API)**: `POST /api/v1/builds` with `mode: "guided"` pauses after each build stage; `advance`, `alternatives`, and `replace` let a client step through and review/swap cards stage by stage. `remove-card`/`remove-card/undo` and `rerun` round out the guided-mode toolkit (mirroring the web build review's Remove Card/Undo and Rerun stage actions).
- **Deck analysis endpoint**: `GET /api/v1/decks/{filename}/analysis` returns commander, color identity, mana curve, pip distribution, mana source breakdown, land summary, and total price for a saved deck.
- **Multi-faced card details**: `GET /api/v1/cards/{name}` now includes a `faces` array (name, type, text, mana value, power/toughness, color identity per face) for split, adventure, transform, modal DFC, flip, and aftermath cards; deck card entries include a `layout` field.
- CORS support for the public REST API (open by default; configurable via `CORS_ALLOWED_ORIGINS`).
- Loyalty is now searchable via `loy:`/`loyalty:` (e.g. `loy>=4`).
- Land build steps show descriptive labels (e.g. "Fetch Lands", "Kindred/Tribal Lands") instead of generic step numbers.
- "Remove Card" button in the web build review lets you remove any card from the deck-in-progress mid-build, with Undo.

## Fixed

- Basic lands no longer show up as "not found" in the card detail API; they now fall back to Scryfall for their info and art.
- Fetch lands are no longer auto-added (or suggested as swap alternatives) unless they can actually search for a basic land type in your deck's colors.
- Tribal ("kindred") lands tied to a specific creature type are no longer added to decks that aren't built around that tribe.
- Fixed missing "Tokens Matter" tag on cards that create a token via a copy effect without saying "creature token".
- "Ramp" is now correctly detected for cards that grant a mana ability without using mana symbols.

## Upgrade notes

1. Rebuild the container: `docker compose up --build --no-deps -d web`.
2. Optional: run a full image cache rebuild (`IMAGE_CACHE_MODE=full`) to download every printing's art up front; otherwise printings are cached on demand as you pick them.
3. No new required environment variables or migrations; `CORS_ALLOWED_ORIGINS` is optional and open by default.
